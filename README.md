## T02: Happiness Scores Prediction

**Description**: This project aims to predict the World Happiness Index score of countries using recent economic and social indicators from 2015 to 2023. By analyzing factors like GDP per capita, various inflation rates, and social variables such as freedom and generosity, we explore how economic stability and societal well-being influence national happiness. A regression model is developed to identify key drivers and forecast happiness levels based on available data.
